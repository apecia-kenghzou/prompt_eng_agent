## Systemic Evaluation

### Strategy Backtesting
- On a quarterly basis, run the complete signal generation and trade plan logic on the last 3 years of historical data for a given asset.
- Generate a backtest report including:
  - Total Profit/Loss
  - Win Rate (%)
  - Average Gain vs. Average Loss
  - Maximum Drawdown
  - Sharpe Ratio
- This report will be used to evaluate and refine the trading strategy and indicator parameters.
