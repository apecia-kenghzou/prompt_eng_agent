## Risk Analysis Workflow

### 1. Parameter & Model Selection
- **Lookback Period**: Use a default 1-year lookback period for historical data but also perform sensitivity analysis with 3-year and 5-year periods.
- **Volatility Model**: Do not assume stationary volatility. Use a GARCH(1,1) model to capture volatility clustering in financial returns.
- **VaR Method**: Use a Monte Carlo simulation-based VaR instead of a simple historical VaR to better model non-normal return distributions.

### 2. Multi-Faceted Risk Assessment
- **Market Risk**:
  - Calculate VaR and CVaR at 95% and 99% confidence levels using a Monte Carlo simulation with at least 10,000 paths.
  - Perform stress tests based on historical events (e.g., 2008 crisis, COVID-19 crash) and hypothetical scenarios.
- **Credit Risk**:
  - For fixed-income assets, analyze the credit ratings distribution (e.g., % of portfolio in AAA, AA, BBB).
  - Calculate the portfolio's overall credit default risk based on CDS spreads or other market indicators.
- **Liquidity Risk**:
  - Analyze the average daily trading volume of each asset in the portfolio.
  - Calculate the number of days it would take to liquidate a position without moving the market price by more than 1%.

### 3. Model Validation
- **Backtesting VaR**: The VaR model must be backtested against historical data. The number of exceptions (days where the actual loss exceeded the VaR estimate) should be consistent with the chosen confidence level. If not, the model must be recalibrated.
- **Sensitivity Analysis**: The final report must include a sensitivity analysis showing how the risk metrics change in response to changes in key assumptions (e.g., volatility, correlations).

### 4. Reporting & Recommendations
- **Executive Summary**: Start the report with a high-level summary of the overall risk exposure.
- **Detailed Breakdown**: Provide a detailed breakdown of risk by type (Market, Credit, Liquidity).
- **Actionable Recommendations**: If the portfolio's risk exceeds predefined thresholds (e.g., Maximum Drawdown > 20%), the report must include specific, actionable recommendations for risk mitigation. Examples:
  - "Hedge equity exposure by purchasing put options on the SPY index."
  - "Reduce allocation to illiquid assets to improve the liquidity profile."
  - "Diversify by adding an allocation to uncorrelated assets like gold."
