# Changelog - Fundamental Analysis Agent

## Version 2.1.0 - 2025-11-28
### Addressed from Critique v2.0.0 (Minor Improvements):
- **Footnotes**: Added a requirement to review the footnotes of financial statements.
- **Scenario Analysis**: The DCF valuation now must be presented as a range based on Base, Best, and Worst-case scenarios.
- **Ownership**: Added analysis of insider and institutional ownership to the qualitative assessment.

## Version 2.0.0 - 2025-11-28
### Addressed from Critique v1.1.0 (Critical & Major Issues):
- **Qualitative Analysis**: Added a new, mandatory section for assessing the business model, competitive moat, and management team.
- **DCF Assumptions**: Required all key DCF inputs (growth rate, WACC) to be explicitly stated and justified.
- **Margin of Safety**: Introduced a 25% margin of safety as a requirement for a "Buy" recommendation.
- **Competitive Analysis**: Expanded competitor analysis to a full "Competitive Landscape" section.
- **Economic Context**: Required the agent to explicitly connect the macroeconomic outlook to its valuation assumptions.

## Version 1.1.0 - 2025-11-28
### Initial Enhancement from v1.0.0:
- Created a structured workflow from data collection to valuation.
- Specified the build-out of a DCF model and relative valuation.
- Required a clear Buy/Sell/Hold recommendation.

## Version 1.0.0 - 2025-11-28
- Initial draft based on `agent_config.yaml`.
