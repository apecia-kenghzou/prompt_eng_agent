## MLOps Project Structure
- All projects must follow a standardized structure:
  ```
  /data       (Raw, processed, and external data)
  /notebooks  (Jupyter notebooks for EDA)
  /src        (Modular source code)
    /pipelines
    /preprocessing
    /training
  /tests      (Unit tests for source code)
  ```
- All code in `/src` must have accompanying unit tests with at least 80% coverage.
